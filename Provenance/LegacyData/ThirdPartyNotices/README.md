# Road Rush third-party notice supplement

Prepared 5–6 November 2026 for Unity6000.6.8f1 / Road Rush0.16 packaging review. This is a notice collection, **not a licence for Road Rush's original code**, and does not authorise publication. Existing DATA_SOURCES.md, THIRD_PARTY.md and provider notices remain applicable.

## Exact retained material

- `SDL3/LICENSE.txt`: unchanged main SDL3.2.28 zlib licence. Both Mac and Windows RoadRushHaptics binaries link the actual SDL static library.
- `SDL3/HIDAPI`: unchanged alternative-licence declaration, BSD-style text and original permissive text. The **permissive BSD-style alternative** is the intended basis; inclusion of a header mentioning GPL does not select GPL. macOS and Windows backends and the macOS compiled libusb backend are traced in the dependency list.
- `SDL3/YUV2RGB-LICENSE.txt`: unchanged Adrien Descamps BSD3 notice. Both platform SDL archives contain yuv2rgb objects.
- `SDL3/Embedded-source-notices.txt`: exact copyright/licence/permission comment blocks from compiled SDL source files and SDL-local compiler dependencies. This retains Sun/fdlibm notices, Gareth McCaughan's zlib qsort notice, PDCLib/public-domain statements, stb alternatives, Khronos/Mesa/MIT/Apache header notices and other embedded notices. Implementation code is not copied. Repeated identical blocks are deduplicated with all contributing paths retained. Conditional header declarations are included conservatively; static-library membership does not establish every function survives final-link dead stripping.
- `SDL3/inclusion-trace.json`: hashes of the actual Mac/Windows static-library link manifests and complete matched compiler-dependency/source paths. Mac:230 source objects/230 dependency files; Windows:246/246. This is a reproducible input trace, not a disassembly-level SBOM.
- `UnityPackages`: exact licence and third-party-notice files from the installed locked packages, including URP17.6 NVIDIA FXAA, Newtonsoft's four MIT components, Mono.Cecil, NUnit and Perfolizer. Editor/test-only dependencies are retained as development notices, not represented as all shipped player code. No PackageCache implementation is vendored.
- `Unity-Companion-License-1.4.txt`: complete legal clauses extracted from the current official Unity page; whitespace normalised. Copyright/terms and source URLs are retained. `Apache-2.0.txt` is the unchanged official plain-text licence needed by traced Apache headers/components.
- `Unity-Player-{macOS,Windows}-Mono-6000.6.8f1.pdf`: official exact-version/platform player third-party reports, linked by Unity's6000.6.8f1 release page. Authoritative PDFs are unchanged. Plain-text companions are for searching. They include Unity's Mono fork, GC, graphics, text and other engine components, including proprietary engine-internal components; these are **not all open source**. They are player reports, not Editor/build-support reports, because those tools are installed separately and not redistributed here.
- `LLVM-mingw/LLVM-LICENSE-WITH-EXCEPTIONS.txt`: exact licence from the actual20261104 toolchain used for the Windows haptics plugin. Compiler-runtime exceptions are retained. Compiler/SDK executables are not distributed. The official20261104 release recipe pins MinGW-w64 commit ee9bd87644156c41072a11ad957d1e11831a72df. Its complete COPYING.MinGW-w64-runtime notice (explicitly intended by upstream for application binaries), AUTHORS and public-domain/ZPL notices are retained with origin hashes. Build-tool-only GPL notices/implementation are excluded. This maps the declared release recipe; it is not a per-symbol proof of the original compiler producer’s build.
- `country-coder`, `CarConcept`, `Newtonsoft`: unchanged project-retained copyright/licence/credit files. Detailed geographic, CC0 texture and vegetation notices remain under their existing Data directories.

`notice-origins.json` maps unchanged local copies to their origins and hashes; `official-license-origins.json` records official downloads and permitted plain-text extraction. `SHA256.json` covers this prepared supplement. Local absolute paths document the audit machine and can be made relative for a public repository without changing the licence text.

## Included and excluded dependencies

Actual native imports were inspected: macOS haptics uses operating-system frameworks; Windows haptics imports Windows/UCRT system DLLs. No Apple/Windows SDK implementation or system curl command-line executable is included. Unity may embed its own curl library, covered by the matching player report. SDL tests/examples are disabled; the unused SDL test Unifont GPL resource, old SDL1.2/LGPL, and arbitrary platform/source trees are not copied. A macOS optional system libusb may be dynamically located by SDL's compiled backend; no libusb binary is bundled or statically linked in the inspected Mach-O imports. This is distinct from the permissively licensed HIDAPI libusb backend source included in SDL.

Notice preservation does not create blanket permission to relicense third-party assets/data. OSM/ODbL database sharing/source-offer treatment and a licence for the original project code still need a separate public-release decision. Do not publish real careers, signing private keys, user settings, build caches, proprietary engine source, original logo-bearing Car Concept assets, Google imagery or unlicensed music.
