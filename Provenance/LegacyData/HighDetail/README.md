# Optional compiled scenery prototype

PantsideBuildings is the 0.11 open-data sample pack, generated from OS OpenMap Local outlines and Welsh Government LiDAR relative roof heights. It is optional and defaults off. Copy its folder into an installed UK country pack's `Detail` directory, enable “Use installed high-detail building packs” in World/Weather settings, and prepare Pantside again. Existing loaded worlds stay unchanged. Detailed and standard prepared caches have separate identifiers. The source release publisher installs this sample alongside the Mac UK pack. LAN guests receive the host's compiled world geometry without needing the source archive or LiDAR files.

The sample includes 410 supported building parts. Four source features are explicitly omitted (courtyard holes and tile-boundary overlap); 16 heights use an art estimate. Outlines are generalised and may combine terraces. Façades, windows and roof styles are fictional. Attribution, source hashes, survey/release dates and reuse information are in buildings-pack.json and ../../DATA_SOURCES.md (project-root DATA_SOURCES.md).

Developer tools: `import_os_buildings.py` extracts a bounded OGL building set; `compile_building_pack.py` combines outlines with DSM minus DTM. `compile_detail_tile.py` currently records Welsh source provenance and compiles quantised terrain/above-ground LODs; adapt source metadata before using another country's data. Raster inputs and the OS archive are disposable after compiled files and their manifest have been verified. No raw automatic deletion is performed. Do not delete installed country databases or real player saves.

Measured 1 km² Pantside results, including five LODs at each setting: original DTM+DSM 4,948,525 bytes; compiled 1 m base 2,912,311 bytes; 2 m base 778,619 bytes; 4 m base 206,649 bytes. Building geometry separately 145,524 bytes. These exclude art textures, processing space and runtime mesh memory. Country totals have not been measured. Packed height tiles can construct meshes at load time; a stored full triangle mesh would generally use more disk.

Absolute replacement terrain remains disabled: this delivery's vertical datum is unconfirmed. Relative DSM-DTM building height inference is independent of that absolute reference. The canopy-height layer includes buildings and vegetation; it is not a classified tree inventory. Sign text and façade designs are not extracted from LiDAR.
