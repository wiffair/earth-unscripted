# Roadmap

Available in the beta: real-road driving, streamed scenery, navigation, saved
locations, vehicle packs and paint, weather/daylight, controller feedback,
fictional radio and simulated nearby rail traffic. Data coverage and scenery
quality vary by location.

Next priorities:

1. Continue investigating occasional 100–200 ms scenery/streaming hitches, cold
   regions and sustained motorway-speed preparation.
2. Broaden international terrain and transport providers with explicit fallbacks.
3. Improve railway networks, station operation, stock selection and live-data
   bindings without presenting inferred allocations as live measurements.
4. Validate updated Windows players on a real Windows machine and refresh downloads.
5. Continue global road/rail junction and bridge-end regressions.
6. Add a native Linux player and launcher, with update support and testing on common distributions.
7. Explore VR headset support: stereo rendering, comfortable cameras, controller input and a tested performance budget.
8. Explore walking, riding buses/trains, player-operated trains, boats and balloons.

Priorities may change as testing and contributions shape the game.
